Support

If you need help with SOCKS5 Profile Manager, the steps below cover the most common questions.

How to add a proxy profile

  1. Open the extension options page.
  2. Enter a profile name, SOCKS5 host, and port.
  3. Optionally edit the bypass rules.
  4. Save the profile.
  5. Open the extension popup and select “Enable SOCKS5”.

SOCKS5 authentication

Chromium does not support username/password authentication for SOCKS5 proxies. The extension therefore supports unauthenticated SOCKS5 endpoints only.

Proxy does not connect

  • Confirm the SOCKS5 host and port are correct.
  • Confirm the SOCKS5 service is reachable from your computer.
  • Confirm the proxy does not require username/password authentication.
  • Temporarily test without custom bypass rules.

Disable the proxy

Open the extension popup and choose “Disable Proxy”. Depending on your saved preference, Chrome will return to the system proxy configuration or direct mode.

Privacy

Configuration is stored locally on your device. See the Privacy Policy for details.

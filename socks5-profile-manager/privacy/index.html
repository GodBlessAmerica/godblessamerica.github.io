Privacy Policy

Last updated: September 11, 2026

SOCKS5 Profile Manager does not collect, transmit, sell, or share personal information.

Information stored locally

The extension stores SOCKS5 proxy profiles, including profile names, proxy hostnames or IP addresses, ports, bypass rules, selected profile state, and extension preferences locally on the user's device using Chrome extension storage.

Information we do not collect

The extension does not collect browsing history, website content, cookies, authentication information, financial information, location information, personal communications, or user activity.

Permissions

Proxy permission: used solely to apply proxy settings explicitly selected by the user.

Storage permission: used solely to save user-created proxy profiles and extension preferences locally on the user's device.

Remote services and tracking

The extension does not use analytics, advertising SDKs, tracking technologies, remote code, or a developer-operated backend.

Data sharing

No user data is sold or transferred to third parties.

Changes to this policy

If this privacy policy changes, the updated version will be published on this page with a revised “Last updated” date.

Contact

For privacy or support questions, please use the support page.

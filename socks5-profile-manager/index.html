About

SOCKS5 Profile Manager uses Chrome's proxy API only to apply the proxy configuration explicitly selected by the user. Proxy profiles and preferences are stored locally with Chrome extension storage.

Important limitation

Chromium does not support username/password authentication for SOCKS5 proxies. Use an unauthenticated SOCKS5 endpoint or a trusted local bridge.

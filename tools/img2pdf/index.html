图片无损转 PDF

把多张 JPG / PNG 按顺序合并为一个 PDF。默认按 72 DPI 处理，即 1 像素 = 1 PDF 点，与原 Python 脚本 img2pdf.convert(..., dpi=72) 的尺寸逻辑一致。

拖入图片，或点击选择

支持 JPG / JPEG / PNG，可一次选择多张。图片只在当前浏览器内存中处理。

还没有添加图片

“无损”指不降低图片像素尺寸、不使用有损质量参数。JPG 会尽量把原始 JPEG 数据直接嵌入 PDF；PNG 解码后以无损 Flate 数据写入，透明通道会保留为 PDF Soft Mask。PDF 文件不一定比原图片总大小更小。

它与原来的 2pdf.py 有什么区别？

原脚本需要手工修改图片文件名，然后运行 Python；这个网页版本直接选择或拖入图片即可，还能调整顺序。

JPG：原 JPEG 字节直接写入 PDF，不重新编码，因此不会再损失一代画质。

PNG：保持原始分辨率并使用无损压缩写入 PDF；带透明背景的 PNG 也支持。

隐私：页面没有上传接口，生成过程全部在浏览器本地完成。

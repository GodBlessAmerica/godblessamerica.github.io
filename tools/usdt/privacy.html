Privacy Policy — USD₮0 Wallet for Arbitrum

Last updated: 2026-09-28

USD₮0 Wallet for Arbitrum is a self-custody browser extension. Its single purpose is to let users create or restore EVM wallet keys locally, inspect Arbitrum One balances, prepare and locally sign USD₮0 token transfers, and broadcast user-approved signed transactions.

Data handled locally

The extension can process wallet recovery phrases, BIP39 passphrases, private keys, public wallet addresses, recipient addresses, transaction amounts, and signed raw transactions. Recovery phrases, passphrases, private keys, and derived seeds are processed only inside the extension wallet page and are not intentionally persisted by the extension to Chrome Storage, LocalStorage, IndexedDB, cookies, or a developer-operated backend.

The extension includes explicit Copy buttons. If a user chooses to copy a recovery phrase, private key, address, signing package, or raw transaction, that value is placed on the operating system clipboard and may remain there according to the operating system and clipboard-manager behavior.

Network requests

The Chrome Web Store build has host access only to the official Arbitrum One JSON-RPC endpoint at https://arb1.arbitrum.io/rpc. When the user explicitly connects, refreshes a balance, prepares a transaction, or broadcasts a signed transaction, public wallet addresses and blockchain transaction data necessary for that operation are transmitted over HTTPS to that RPC endpoint. Private keys, recovery phrases, BIP39 passphrases, and derived seeds are not included in RPC requests.

No analytics, advertising SDKs, tracking pixels, remote executable code, or developer-operated wallet backend are included.

Sharing and sale of data

The developer does not sell user data and does not use user data for advertising, creditworthiness, lending, or unrelated purposes. Blockchain-related data is transmitted only as necessary to provide the extension's disclosed wallet functionality through the Arbitrum RPC service. Signed transactions that are broadcast become part of public blockchain infrastructure according to the operation of Arbitrum One.

Retention

The extension does not intentionally retain secret wallet material after the wallet tab is closed. JavaScript and browser memory cannot guarantee immediate physical erasure of prior memory contents, so users handling high-value keys should use a dedicated offline signing environment.

Security

Network requests use HTTPS. The extension bundles its executable code locally and does not load remote JavaScript. Users remain responsible for safeguarding their recovery phrase, passphrase, private key, device, browser profile, clipboard, and backups.

Chrome Web Store Limited Use

The use of information handled by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's user-facing self-custody wallet functionality.

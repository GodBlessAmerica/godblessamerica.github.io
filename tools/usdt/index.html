Implementation notes. Single-file Arbitrum One self-custody wallet supporting BIP39 24-word recovery phrases, BIP32/BIP44 derivation at m/44'/60'/0'/0/index, explicit display of the private key for the selected derived address, raw private keys, watch-only mode, offline key verification, local QR generation, local transaction signing and air-gapped signing packages. No external JavaScript, CSS, fonts, analytics, wallet extension or backend is used. The only network operation is explicit JSON-RPC fetch() to the endpoint you enter. The Arbitrum One chain ID and USD₮0/USDT0 token contract are locked in source and checked before online sending. The token symbol is informational because branding characters may change; the locked address, chain ID, contract bytecode and 6-decimal metadata are the security checks.
